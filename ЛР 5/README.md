# Лабораторная работа 5: Стек, Быстрая сортировка и интегрирование методом Симпсона

## Описание
Данная лабораторная работа демонстрирует работу со следующими алгоритмами и структурами данных:

### Структуры данных:
1. **Стек на базе связного списка** - для хранения координатных пар
2. **Бинарное дерево поиска** - для эффективного хранения и поиска отсортированных данных

### Алгоритмы:
1. **Быстрая сортировка (Quick Sort)** - для сортировки координат по x-координате
2. **Метод Симпсона** - для численного интегрирования между точками
3. **Линейная интерполяция** - для вычисления промежуточных значений

## Функциональность
- Чтение координатных пар из файла `test.txt`
- Проверка уникальности x-координат
- Сортировка координат с помощью быстрой сортировки
- Построение бинарного дерева поиска
- Численное интегрирование методом Симпсона
- Вывод результатов и структуры дерева

## Использование
```bash
python main.py
```

## Тестирование
```bash
python test_lab5.py
```

## Формат входных данных
Файл `test.txt` должен содержать пары чисел (x, y), разделенных пробелом:
```
3 9
1 1
7 49
2 4
5 25
```

## Алгоритмическая сложность
- **Стек**: O(1) для push/pop операций
- **Быстрая сортировка**: O(n log n) в среднем случае, O(n²) в худшем
- **Бинарное дерево поиска**: O(log n) для поиска/вставки в среднем случае
- **Метод Симпсона**: O(1) для одного интервала, O(n) для всех интервалов
